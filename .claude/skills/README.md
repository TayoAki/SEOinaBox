# Vendored agent skills

These folders are copied unmodified from [mattpocock/skills](https://github.com/mattpocock/skills)
(plugin version 1.3.2, commit `5863806dd4e15c63174bee4e7515a4256792ecfa`), MIT licensed. See `LICENSE-mattpocock-skills`.

They are the 27 skills that repo ships in its plugin: the engineering flow
(`setup-matt-pocock-skills`, `wayfinder`, `grill-with-docs`, `to-spec`, `to-tickets`,
`implement`, `tdd`, `code-review` and friends) plus the productivity set.
Start with `ask-matt` to see how they fit together.

To update, copy the same folders again from a fresh clone of that repo.
